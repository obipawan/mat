Rules:
- Widget file name = `PascalCase(type) + "Widget.qml"` (`controlCenter` → `ControlCenterWidget.qml`). `BarWidgetRegistry.source(type)` returns `"widgets/" + that name`.
- A surface directory contains only that surface's files. Shared pieces become primitives (with a contract) or stay private to the surface.
- `tests/` and `scripts/` are never imported by `shell/`.

## 2. Module Layers and Import Rules

```text
 lib/*.mjs  ──►  MatShell.Tokens  ──►  MatShell.Services  ──►  MatShell.State  ──►  MatShell.Primitives  ──►  bar/  surfaces/  ──►  shell.qml
 (pure JS)       (generated)            (side effects)          (ShellState)          (M3*)                    (composition)
```

| Layer | May import / reference | Must not reference |
|---|---|---|
| `lib/*.mjs` | Other `lib/*.mjs` via `./name.mjs` | `Qt`, `Quickshell`, `Tokens`, any QML type, `console.log` (G20) |
| `MatShell.Tokens` | `QtQuick`, `Quickshell`, `Quickshell.Io` | Everything else |
| `MatShell.Services` | Tokens, `lib/`, Quickshell modules, services **below** it in the DAG (§2.1) | State, Primitives, bar, surfaces |
| `MatShell.State` | Tokens, Services, `lib/` | Primitives, bar, surfaces |
| `MatShell.Primitives` | Tokens, `ShellState`, `BarService`, `KeyboardService`, `lib/popoverPlacement.mjs`, `lib/wheel.mjs`, other primitives | Every other service (G17), bar, surfaces |
| `bar/`, `surfaces/<x>/` | All modules above; files in their own directory | Files of another surface directory |
| `shell.qml` | Everything | — |

QML import lines (exact):

```qml
import QtQuick
import QtQuick.Layouts
import Quickshell
import Quickshell.Wayland
import MatShell.Tokens
import MatShell.Services
import MatShell.State
import MatShell.Primitives
import "../../lib/widgetOptions.mjs" as WidgetOptions   // relative path from the importing file
```

Only the modules in `scripts/lint-shell.py` `ALLOWED_IMPORTS` may be imported (G15). `QtQuick.Controls` in any form is banned because its styles fight the M3 primitives.

### 2.1 Service Dependency DAG (no cycles)

A service may reference only services on an **earlier** row.

| Row | Services |
|---|---|
| 0 | `CompositorService`, `BarWidgetRegistry`, `KeyboardService`, `TelemetryService`, `SettingsIndex` |
| 1 | `ConfigService` |
| 2 | `AccessibilityService`, `AudioService`, `BrightnessService`, `BatteryService`, `NetworkService`, `BluetoothService`, `MediaService`, `WeatherService`, `SessionService` |
| 3 | `BarService` (Config, Compositor, Registry), `NotificationService` (Config), `ThemeService` (Config), `KeybindService` (Config, Compositor), `CaptureService` (Compositor), `PolkitService`, `LauncherService` (Compositor) |

`ShellState` (State layer) may read any service.

## 3. Runtime Composition (`shell/shell.qml`)

`shell.qml` is the only place that instantiates top-level windows. It grows one line per task. Its final form:

```qml
import QtQuick
import Quickshell
import MatShell.Tokens
import MatShell.Services
import MatShell.State
import "bar"
import "surfaces/corners"
import "surfaces/controlcenter"
// … one import per surface directory

ShellRoot {
    Bars {}                                                   // Variants { model: BarService.instances } → BarWindow
    PrivacyFallback {}                                        // Overlay pill when no visible bar hosts privacy/recording
    Variants { model: Quickshell.screens; ScreenCorners {} }  // one per screen
    Variants { model: Quickshell.screens; DesktopWidgetsLayer {} }
    ControlCenter {}  NotificationCenter {}  CalendarWeatherPanel {}  MediaPopover {}   // Lane 2 (one window each)
    NotificationToasts {}  OsdHud {}                                                   // Lane 1
    AppCommandLauncher {}  WorkspaceOverview {}  PowerSessionMenu {}  PolkitDialog {}
    ScreenCaptureHud {}  WallpaperThemePicker {}                                       // Lane 3
    LockScreen {}                                                                      // WlSessionLock
    SettingsWindow {}                                                                  // FloatingWindow, hidden until settingsRequested
    DebugIpc {}                                                                        // smoke-test introspection
}
```

Screen placement:
- **Lane 2 popovers** are single windows whose `screen` follows the trigger: `screen: ShellState.popoverTrigger?.QsWindow.window?.screen ?? CompositorService.focusedScreen` (owned by `M3Popover`).
- **Lane 3 modals, OSD, toasts** use `screen: CompositorService.focusedScreen`.
- **Bars, corners, desktop widgets, lock surfaces** are per screen (`Variants`).

## 4. Window and Layer Matrix (normative; resolves C01–C04)

| Surface | Root type | `WlrLayershell.namespace` | Layer | Exclusion | `keyboardFocus` | Input mask |
|---|---|---|---|---|---|---|
| Bar | `PanelWindow` | `"mat-bar-" + bar.id` | `Top` | `exclusiveZone: BarGeometry.exclusiveZone(bar, shown)` | `None`; `OnDemand` while `ShellState.barFocusActive` | shown: hit strip from screen edge to inner edge; hidden: `barRevealStrip` (4px) |
| Privacy fallback | `PanelWindow` | `"mat-privacy-fallback"` | `Overlay` | `Ignore` | `None` | the pill |
| Screen corners | `PanelWindow` (via `M3ScreenCorners`) | `"mat-corners"` | `Overlay` | `Ignore` | `None` | empty `Region {}` |
| Desktop widgets | `PanelWindow` | `"mat-desktop-widgets"` (`"mat-desktop-widgets-peek"` in Peek) | `Background` (`Overlay` in Peek) | `Ignore` | `None` (`OnDemand` in Peek) | visible widget boxes; scrim in Peek; empty when disabled |
| Control center | `M3Popover` | `"mat-control-center"` | `Top` | `Ignore` | `OnDemand` (`Exclusive` while the Wi-Fi password field has focus) | full screen minus `BarService.regions(screen)` |
| Notification center | `M3Popover` | `"mat-notifications"` | `Top` | `Ignore` | `OnDemand` | full screen minus bars |
| Calendar & weather | `M3Popover` | `"mat-calendar"` | `Top` | `Ignore` | `OnDemand` | full screen minus bars |
| Media | `M3Popover` | `"mat-media"` | `Top` | `Ignore` | `OnDemand` | full screen minus bars |
| Toasts | `PanelWindow` | `"mat-toasts"` | `Top` (`Overlay` for Critical over fullscreen) | `Ignore` | `None` (`OnDemand` during inline reply) | `Region { item: toastColumn }` |
| OSD | `PanelWindow` | `"mat-osd"` | `Overlay` | `Ignore` | `None` (always) | empty `Region {}` |
| Launcher | `PanelWindow` | `"mat-launcher"` | `Overlay` | `Ignore` | `Exclusive` | full screen |
| Overview | `PanelWindow` | `"mat-overview"` | `Overlay` | `Ignore` | `Exclusive` | full screen |
| Power | `PanelWindow` | `"mat-power"` | `Overlay` | `Ignore` | `Exclusive` | full screen |
| Polkit | `PanelWindow` | `"mat-polkit"` | `Overlay` | `Ignore` | `Exclusive` | full screen |
| Capture | `PanelWindow` | `"mat-capture"` | `Overlay` | `Ignore` | `Exclusive` (drops to `None` and closes when recording starts) | full screen |
| Theme studio | `PanelWindow` | `"mat-theme-studio"` | `Top` | `Ignore` | `Exclusive` | the drawer; anchors `bottom`, `left`, `right` |
| Lock | `WlSessionLock` → `WlSessionLockSurface` per screen | — | session lock | — | lock surface | — |
| Settings | `FloatingWindow` | — (xdg toplevel, title `"Settings — Mat Shell"`) | — | — | normal | — |

Every `PanelWindow` sets `color: "transparent"` and draws its own `M3Surface`. Every visibility switch binds to state (`visible: ShellState.activeModal === "power"`); never call `show()` imperatively.

## 5. Name Maps

### 5.1 Lane names (exact strings)

| Lane | Field | Values |
|---|---|---|
| 2 (popovers, max one) | `ShellState.activePopover` | `""`, `"control_center"`, `"notifications"`, `"calendar"`, `"media"` |
| 3 (modals, max one) | `ShellState.activeModal` | `""`, `"launcher"`, `"overview"`, `"power"`, `"polkit"`, `"capture"`, `"theme_studio"`, `"widget_peek"` |
| Launcher mode | `ShellState.launcherMode` | `"apps"`, `"win"`, `"calc"`, `"clip"`, `"cmd"`, `"emoji"` |

Widget `type` values are camelCase (`controlCenter`); lane names are snake_case (`control_center`). Never mix them (C07).

### 7.4 `IpcHandler { target: "debug" }` (in `DebugIpc.qml`; read-only, no side effects)

Every function returns `string` (compact JSON) so `tests/smoke/ipc-script.txt` can assert on it with `=> regex`.

| Function | Returns |
|---|---|
| `state()` | `{activePopover, activeModal, launcherMode, sessionLocked, barFocusActive}` |
| `config()` | `ConfigService.config` |
| `bars()` | `[{id, screen, shown, exclusiveZone}]` for `BarService.instances` plus `insets` of the focused screen |
| `compositor()` | `{kind, focusedWorkspaceId, workspaces: n, activeWindowAppId}` |
| `audio()` / `battery()` / `network()` / `media()` / `notifications()` | the read-only properties of that service |
| `keybindConflict(id: string, chord: string)` | the action id that already uses `chord`, or `""` (no change is saved) |

Core actions that may be rebound but never unbound: `toggleLauncher`, `openSettings`, `togglePower`. The canonical action table lives in `lib/keybinds.mjs` `ACTIONS` (02-contracts §2.11).
